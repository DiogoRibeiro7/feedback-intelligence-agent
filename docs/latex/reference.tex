\begin{abstract}
\noindent
This is the reference half of the \projectname{} technical documentation at
revision \texttt{\projectrevision}: every public module, class, function,
method, data contract, command-line command, HTTP endpoint, and configuration
variable, with signatures taken directly from the source, plus the mathematics
the package implements.

It deliberately contains no architecture narrative and no engineering
material. Those form the second and third parts of the complete manual,
\srcfile{docs/latex/main.tex}, which includes this same content unchanged.
\end{abstract}
