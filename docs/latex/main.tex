\begin{abstract}
\noindent
This manual documents the \projectname{} repository at revision
\texttt{\projectrevision}. It is organised as three independent references.
The \emph{Reference Manual} enumerates what the repository exposes: every
public module, class, function, data contract, command-line command, HTTP
endpoint, and configuration variable, with signatures taken directly from the
source. The \emph{Software Architecture} part explains how those objects are
arranged into components, how they depend on one another, and how a request
flows through them. The \emph{Engineering} part explains how the software is
developed, verified, built, reproduced, packaged, and released.

Every derived statement in this manual is extracted from the repository by the
generator in \srcfile{docs/tools/}; authored commentary is confined to the
chapter introductions, the mathematical exposition, and the architecture
decision records. Where a rationale could not be established from repository
evidence, this manual says so rather than inventing one.
\end{abstract}
