# Support

Use the following channels:

- Bugs and reproducible defects: open a GitHub issue with the bug report template.
- Feature proposals: open a GitHub issue with the feature request template.
- Security vulnerabilities: report privately through GitHub Security Advisories.
- Open-ended implementation questions: use GitHub Discussions.

This repository is a portfolio-grade engineering project, not a hosted service.
Please include commands, environment details, and sanitized logs when asking for
help.
